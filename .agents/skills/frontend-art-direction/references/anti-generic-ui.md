# Anti-Generic UI Checklist

Treat these as warning signs, not absolute bans.

## Layout
- Centered headline + centered paragraph + two buttons + screenshot for every landing page.
- Repeating 3/4-column card rows as the only structural device.
- Every section inside a bordered rounded rectangle.
- Excessive empty space in tools that users operate all day.
- No meaningful difference between primary, secondary, and supporting regions.

## Typography
- Same font family, weight, tracking, and rhythm for every project.
- Heading size used as the only hierarchy.
- Weak label/body distinction.
- Numeric data not aligned or formatted for comparison.

## Color
- Purple-to-blue gradient by default.
- Gray text on colored backgrounds with weak contrast.
- Many equally loud accents.
- Semantic status colors used decoratively.

## Shape
- Rounded square behind every icon.
- Pills for non-pill concepts.
- Same large radius on cards, buttons, inputs, tables, dialogs, and images.
- Shadow on every surface.

## Content
- Fake metrics with no product context.
- Generic labels: "Continue", "Learn more", "Item 1".
- Empty states that only say "No data".
- Error states with no recovery.

## Motion
- Bounce/elastic easing everywhere.
- Animation on every hover.
- Long entrance sequences that delay task completion.

## Recovery
If the design feels generic:
1. Re-state the product's task and user.
2. Pick one stronger composition decision.
3. Improve typography before adding effects.
4. Remove containers that do not carry structural meaning.
5. Add one product-specific signature detail.
