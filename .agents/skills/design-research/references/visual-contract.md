# Visual Contract

A design direction is ready when it answers all of these.

## Thesis
One sentence describing the visual system and why it fits the product.

## Signature
One memorable, reusable decision:
- a distinctive navigation rhythm;
- an editorial type relationship;
- a technical grid;
- a material/texture language;
- a data-visualization motif;
- a spatial behavior;
- a subtle but recognizable motion system.

The signature must support the product. It must not be decoration pasted on top.

## Typography
Define:
- display/heading/body/label/mono roles;
- size and line-height logic;
- numeric treatment;
- maximum line lengths;
- when weight vs size creates hierarchy.

## Color
Define:
- canvas;
- primary text;
- secondary text;
- surfaces;
- borders;
- accent;
- positive/warning/negative/info;
- focus ring;
- chart palette if relevant.

## Spatial system
Define:
- max-width or full-width logic;
- grid/columns;
- page gutters;
- vertical rhythm;
- dense vs relaxed zones;
- section separation strategy.

## Shape/elevation
Define:
- corner philosophy;
- border usage;
- shadow/elevation rules;
- when a surface deserves a container.

## Motion
Define:
- durations;
- easing family;
- entrance behavior;
- state transitions;
- reduced-motion fallback.

## Anti-reference
List visible patterns to avoid for this product.
