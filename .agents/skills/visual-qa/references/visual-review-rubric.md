# Visual Review Rubric

## Hierarchy
PASS when the eye lands in the intended order and primary action is obvious.

## Composition
PASS when space feels allocated intentionally; no accidental dead zones or crowding.

## Typography
PASS when:
- headings wrap intentionally;
- body measure is readable;
- labels are distinct;
- data numerals align;
- text does not collide or orphan badly.

## Alignment
PASS when shared edges and baselines are visually consistent.
Check optical alignment, not only mathematical alignment.

## Density
PASS when task frequency and information volume match the spacing.
ERP/admin surfaces may be denser than marketing pages.

## Surfaces
PASS when cards, borders, elevation, and backgrounds communicate structure rather than decorate everything.

## Responsive
PASS when content priority remains clear after reflow.
Mobile is not a scaled-down desktop screenshot.

## States
PASS when hover/focus/active/disabled/loading/error states do not break layout or hierarchy.

## Signature
PASS when the interface has a recognizable context-specific visual decision without undermining clarity.
