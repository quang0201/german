# Data-Dense Patterns

## Toolbar
A useful operational toolbar often contains:
- title/context;
- search;
- essential filters;
- date/range selector;
- primary action;
- saved view or export if genuinely frequent.

Do not turn every secondary control into a prominent button.

## KPI treatment
Use KPI blocks only for values that:
- frame the decision below;
- have meaningful comparison or threshold;
- are used frequently.

Include comparison context where needed:
- prior period;
- target;
- threshold;
- trend.

## Table column priority
Classify:
- identity;
- decision-critical;
- supporting;
- optional;
- actions.

On smaller widths, hide or collapse optional columns first.

## Status
Prefer concise semantic status:
- icon + text;
- restrained color;
- readable contrast.

Avoid giant colored pills for every cell.

## Drill-down
Keep the list context when opening detail:
- side panel;
- split view;
- route that preserves filters/scroll state.

Choose based on task depth and screen width.
